# 建立项目目录和 Agent 开发入口

## 目标

为机器人避障工作台建立可检出的项目目录，并让后续 Agent 能找到课程依据、产品规格、架构边界和首个开发阶段。

## 验收

- Git 跟踪前后端项目目录。后端明确仿真、算法、场景、实验和传输各自的职责，前端明确 API、界面和画布各自的职责。
- README、AGENTS 和 Trellis 规格索引指向实际存在的规格与架构说明。保留已确认的课堂演示和需求变更约定。
- 本次只交付目录和说明文档。产品实现、依赖安装和前后端脚手架留给后续 P0。
- 课程源资料留在本地。检查提交范围，归档本任务，并将工作与归档一并推送到 origin/main。
